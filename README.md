# Splendor — Gem District

เว็บเกม Splendor แบบเล่นคนเดียวกับ AI หรือเล่นออนไลน์ 2 คน สร้างด้วย HTML, CSS และ JavaScript ล้วน จึงไม่ต้องติดตั้งแพ็กเกจใด ๆ

## เปิดเล่น

### เล่นกับ AI

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที

### เล่นออนไลน์ 2 คน

เริ่มเว็บเซิร์ฟเวอร์จากโฟลเดอร์นี้ แล้วเปิดลิงก์ที่แสดงในหน้าต่างคำสั่ง:

```bash
node server.js
```

ผู้เล่นคนแรกเลือก **เล่นออนไลน์** และกดสร้างห้อง จากนั้นส่งรหัสหกตัวอักษรให้เพื่อน ผู้เล่นคนที่สองเลือก **เล่นออนไลน์** เช่นกัน ใส่รหัสห้อง และกดเข้าร่วม เกมจะซิงก์กระดานและตาเล่นอัตโนมัติทุกครั้งที่จบตา

สำหรับนำขึ้นอินเทอร์เน็ต ให้โฮสต์ทั้งโฟลเดอร์นี้บนแพลตฟอร์มที่รองรับ Node.js แล้วกำหนดคำสั่งเริ่มต้นเป็น `node server.js` (แพลตฟอร์มจะส่งพอร์ตผ่านตัวแปร `PORT` ให้อัตโนมัติ)

## สิ่งที่มีในเกม

- ตลาดไพ่พัฒนา 3 ระดับ พร้อมกองไพ่และการเติมไพ่ใหม่
- อัญมณี 5 สี, ทองคำแบบ Wild และส่วนลดถาวรจากโบนัสไพ่
- ซื้อไพ่, จองไพ่หน้าโต๊ะหรือกองคว่ำ, จำกัดไพ่จอง 3 ใบ
- ระบบขุนนาง, คะแนนศักดิ์ศรี และเงื่อนไขชนะเมื่อจบรอบ
- AI คู่แข่งที่เลือกซื้อ จอง และเก็บอัญมณีตามสถานการณ์
- ห้องออนไลน์ 2 คนด้วยรหัสห้อง พร้อมซิงก์กระดานจากเซิร์ฟเวอร์กลาง
- กติกาจำกัดอัญมณี 10 เหรียญ พร้อมหน้าคืนเหรียญ
- หน้าจอรองรับมือถือ แท็บเล็ต และเดสก์ท็อป
